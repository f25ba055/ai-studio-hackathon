# 🏔️ 群馬県観光地レビューアプリ - Python版

## 📋 必要な環境
- **Python 3.7以上**
- **pip**（Pythonパッケージ管理ツール）
- **Webブラウザー**（Chrome/Firefox/Safari等）

または

- **Docker Desktop**（Dockerを使う場合）

## 🚀 セットアップ手順

### 方法1: Docker（推奨）

**前提条件**: Docker Desktopがインストールされていること

```bash
# イメージをビルドして起動
docker-compose up --build

# バックグラウンドで起動する場合
docker-compose up -d

# 停止する場合
docker-compose down
```

**ブラウザでアクセス**:
- トップページ: http://localhost:3001
- 観光スポット: http://localhost:3001/spots.html
- イベント情報: http://localhost:3001/events.html

**データベースを再初期化する場合**:
```bash
docker-compose down -v
docker-compose up -d
```

### 方法2: 手動セットアップ

```bash
# 1. 必要なパッケージをインストール
pip3 install flask flask-cors

# 2. データベースを初期化
python3 database/init_db.py

# 3. サンプルデータを追加
python3 database/add_tourist_spots.py
python3 database/add_sample_users.py
python3 database/add_sample_reviews.py
python3 database/add_sample_events.py

# 4. サーバーを起動
cd app
python3 app.py
```

**ブラウザでアクセス**:
- トップページ: http://127.0.0.1:3001
- 観光スポット: http://127.0.0.1:3001/spots.html
- イベント情報: http://127.0.0.1:3001/events.html

## 🔧 よくあるトラブルと解決方法

### ❌ 「python: command not found」
**原因**: Pythonがインストールされていません
**解決**: https://www.python.org からPythonをインストール

### ❌ 「No module named 'flask'」
**原因**: Flaskがインストールされていません
**解決**:
```bash
pip install flask flask-cors
```

### ❌ ポート3001が使用中
**原因**: 他のアプリケーションがポート3001を使用
**解決**: app/config.pyのPORT設定を編集
```python
PORT = 8080  # 3001から8080に変更
```

### ❌ 観光地が表示されない
**原因**: データベースが初期化されていない
**解決**:
```bash
python3 database/init_db.py
python3 database/add_tourist_spots.py
python3 database/add_sample_users.py
python3 database/add_sample_reviews.py
python3 database/add_sample_events.py
```

### ❌ Docker起動時にコンテナ名の競合エラー
**原因**: 既存のコンテナが残っている
**解決**:
```bash
docker rm -f gunma-tourism-app
docker-compose up -d
```

## 🎓 学習のポイント

### データベースの確認
```bash
# SQLiteコマンドラインで確認
sqlite3 tourism_review.db

# テーブル一覧
.tables

# ユーザー確認
SELECT * FROM users;

# 観光地確認
SELECT spot_name, address FROM tourist_spots LIMIT 5;

# レビュー確認
SELECT u.name, s.spot_name, r.rating FROM reviews r
JOIN users u ON r.user_id = u.user_id
JOIN tourist_spots s ON r.spot_id = s.spot_id
LIMIT 5;

# イベント確認
SELECT event_name, event_date, location, area FROM events LIMIT 5;

# 月別イベント確認
SELECT event_name, event_date FROM events
WHERE substr(event_date, 6, 2) = '08'
ORDER BY event_date;

# 終了
.quit
```

## 📡 主要なAPI一覧

### 観光地API
- `GET /api/spots` - 観光地一覧取得
- `GET /api/spots/{id}` - 観光地詳細取得
- `GET /api/spots/search?keyword={keyword}` - 観光地検索

### レビューAPI
- `GET /api/reviews/{spot_id}` - レビュー一覧取得
- `POST /api/reviews` - レビュー投稿
- `DELETE /api/reviews/{review_id}` - レビュー削除

### イベントAPI
- `GET /api/events` - イベント一覧取得
- `GET /api/events?month={month}` - 月別イベント取得
- `GET /api/events?area={area}` - 地域別イベント取得
- `GET /api/events/search?q={keyword}` - イベント検索

### 認証API
- `POST /api/auth` - ユーザー認証
- `POST /api/users` - ユーザー登録
