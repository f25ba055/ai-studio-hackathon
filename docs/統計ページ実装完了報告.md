## 📊 実装概要

**URL**: http://localhost:3001/stats.html

**目的**: 群馬県観光データの統計情報を可視化するダッシュボード

**デザイン**: カード形式で各統計を表示（既存のspot-cardのスタイルを流用）

## ✅ 実装された機能（4つのセクション）

### 1. 基本統計カード

数値のみのシンプルな表示

**表示項目**:
- 登録観光地数
- 総レビュー数
- 登録ユーザー数
- 開催予定イベント
- 総合平均評価

**実装ファイル**:
- `frontend/stats.html`: HTMLマークアップ
- `frontend/stats.js`: `displaySummary()` 関数
- `app/repositories/stats_repository.py`: `fetch_summary()` メソッド

---

### 2. 人気観光地ランキング TOP5

評価順で上位5件を表示

**表示内容**:
- 順位（1位〜5位）
- メダル表示（🥇🥈🥉）
- 観光地名
- 平均評価と件数

**実装ファイル**:
- `frontend/stats.js`: `displayTopSpots()` 関数
- `app/repositories/stats_repository.py`: `fetch_top_spots()` メソッド

**ソート順**:
1. 平均評価の高い順
2. レビュー数の多い順
3. spot_idの昇順

---

### 3. 地域別観光地数（横棒グラフ風）

地域ごとの観光地数をビジュアル表示

**表示地域**:
- 前橋・赤城
- 高崎・富岡
- 草津・四万
- 水上・尾瀬
- 伊香保・榛名
- その他

**実装ファイル**:
- `frontend/stats.js`: `displaySpotsByArea()`, `createBarChartItem()` 関数
- `app/repositories/stats_repository.py`: `fetch_spots_by_area()` メソッド

**実装方法**:
- HTMLの`<div>`要素の幅を動的に計算
- CSS: `background-color`, `width` で棒を表現
- グラフライブラリ不要

---

### 4. 月別イベント数（棒グラフ風）

月ごとのイベント開催数を表示

**表示内容**:
- 1月〜12月の各月
- イベント数の多い順にソート
- 0件の月は非表示

**実装ファイル**:
- `frontend/stats.js`: `displayEventsByMonth()`, `createBarChartItem()` 関数
- `app/repositories/stats_repository.py`: `fetch_events_by_month()` メソッド

## 💾 実装されたAPIエンドポイント

### 1. GET /api/stats/summary
基本統計情報を取得

**レスポンス例**:
```json
{
  "total_spots": 21,
  "total_reviews": 38,
  "total_users": 4,
  "total_events": 20,
  "avg_rating_overall": 4.2
}
```

**実装箇所**:
- Controller: `app/controllers/stats_controller.py`
- Service: `app/services/stats_service.py`: `get_summary()`
- Repository: `app/repositories/stats_repository.py`: `fetch_summary()`

---

### 2. GET /api/stats/spots-by-area
地域別観光地数を取得

**クエリパラメータ**:
- `area` (optional): 特定地域でフィルター

**レスポンス例**:
```json
[
  {"area": "maebashi", "area_name": "前橋・赤城", "count": 6},
  {"area": "takasaki", "area_name": "高崎・富岡", "count": 4},
  {"area": "kusatsu", "area_name": "草津・四万", "count": 3}
]
```

**実装箇所**:
- Controller: `app/controllers/stats_controller.py`
- Service: `app/services/stats_service.py`: `get_spots_by_area()`
- Repository: `app/repositories/stats_repository.py`: `fetch_spots_by_area()`

**地域判定ロジック**:
- addressカラムから地域を判定
- 地域名の日本語マッピング実装済み

---

### 3. GET /api/stats/events-by-month
月別イベント数を取得

**レスポンス例**:
```json
[
  {"month": 1, "month_name": "1月", "count": 2},
  {"month": 2, "month_name": "2月", "count": 1},
  {"month": 8, "month_name": "8月", "count": 4}
]
```

**実装箇所**:
- Controller: `app/controllers/stats_controller.py`
- Service: `app/services/stats_service.py`: `get_events_by_month()`
- Repository: `app/repositories/stats_repository.py`: `fetch_events_by_month()`

**SQLロジック**:
```sql
SELECT
  CAST(substr(event_date, 6, 2) AS INTEGER) as month,
  COUNT(*) as count
FROM events
GROUP BY month
ORDER BY month
```

---

### 4. GET /api/stats/top-spots
人気観光地ランキング取得

**クエリパラメータ**:
- `limit` (optional): 取得件数（デフォルト: 5）

**レスポンス例**:
```json
[
  {
    "spot_id": 15,
    "spot_name": "こんにゃくパーク",
    "avg_rating": 4.5,
    "review_count": 4
  },
  {
    "spot_id": 1,
    "spot_name": "草津温泉",
    "avg_rating": 4.7,
    "review_count": 3
  }
]
```

**実装箇所**:
- Controller: `app/controllers/stats_controller.py`
- Service: `app/services/stats_service.py`: `get_top_spots()`
- Repository: `app/repositories/stats_repository.py`: `fetch_top_spots()`
