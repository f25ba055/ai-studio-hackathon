# 学生向けバグ修正課題 - バグ候補案

## 📋 目標

- **初級**: 10問
- **中級**: 10問
- **上級**: 5問
- **合計**: 25問

## 🎯 設計方針

### 重要な制約
1. **バグ同士は関連していない方が良い**
   - グループワークで並行作業できるように
   - 「このバグを解決しないと次に取り組めない」を避ける
2. **影響範囲が独立している**
   - 1つのファイル/機能に閉じている
   - 他の学生の作業をブロックしない
3. **段階的な難易度**
   - 初級: 見つけやすく、修正も簡単
   - 中級: 原因特定に調査が必要
   - 上級: セキュリティや設計の理解が必要
