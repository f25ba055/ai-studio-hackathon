# promotion.html バグ候補案（超初級 10個）

## 📋 概要

**目的**: HTML/CSSのみで構成された宣伝ページに、超初級者向けのバグを10個仕込む

**対象ファイル**: `/frontend/promotion.html`

**難易度**: 超初級（JavaScriptなし、目で見て分かる、HTMLとCSSの基礎のみ）

**独立性**: 全て独立したバグなので、10人で並行作業可能

---

## 🐛 バグ一覧（10個）

### 1. スペルミス系（5個）

#### バグ1: 「群馬県」→「群馬件」
**場所**: 複数箇所（ヒーローセクション、フッターなど）

**現在の正しいコード**:
```html
<h1>🏔️ 群馬の魅力を発見しよう！</h1>
<p>&copy; 2025 群馬県観光ポータル</p>
```

**バグを仕込んだコード**:
```html
<h1>🏔️ 群馬の魅力を発見しよう！</h1>
<p>&copy; 2025 群馬件観光ポータル</p>
```

**期待される修正**: 「群馬件」→「群馬県」

---

### 2. HTMLタグミス系（3個）

### 3. CSSミス系（2個）

#### バグ9: 色コードのミス `#667eea` → `#667ea`
**場所**: ヒーローセクションのCSS

**現在の正しいコード**:
```css
.hero {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    color: white;
    text-align: center;
    padding: 80px 20px;
}
```

**バグを仕込んだコード**:
```css
.hero {
    background: linear-gradient(135deg, #667ea 0%, #764ba2 100%);
    color: white;
    text-align: center;
    padding: 80px 20px;
}
```

**期待される修正**: `#667ea` → `#667eea`（6桁に修正）

**見た目の変化**: ヒーローセクションの背景色がおかしくなる（無効な色コード）

---

#### バグ10: フォントサイズのミス `3rem` → `0.3rem`
**場所**: ヒーローセクションの見出し

**現在の正しいコード**:
```css
.hero h1 {
    font-size: 3rem;
    margin-bottom: 20px;
    text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
}
```

**バグを仕込んだコード**:
```css
.hero h1 {
    font-size: 0.3rem;
    margin-bottom: 20px;
    text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
}
```

**期待される修正**: `0.3rem` → `3rem`

**見た目の変化**: タイトルが極小サイズになり、ほぼ見えなくなる

## 🎯 学習目標

### バグ1〜5（スペルミス）で学べること
- テキストの校正力
- HTMLの構造理解
- ブラウザで実際の表示を確認する習慣

### バグ6〜8（HTMLタグミス）で学べること
- HTMLタグの正しい使い方
- 閉じタグの重要性
- リンクの`href`属性の理解
- ブラウザ開発者ツールでのデバッグ（404エラー確認）

### バグ9〜10（CSSミス）で学べること
- CSSの色コード（6桁のHEX形式）
- CSSの単位（rem）
- CSSの修正がすぐに視覚的に分かる体験

## 🛠️ バグ仕込み手順（実装時）

1. `/frontend/promotion.html` をバックアップ
2. 上記の「バグを仕込んだコード」に従って修正
3. Dockerを再ビルド
4. ブラウザで確認（バグが視覚的に分かるか確認）
5. GitHubにpushして学生に配布
